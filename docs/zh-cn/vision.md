# axiom 愿景纲领：交叉宪法层与一致性机器

> **性质**：本卷是 axiom 的纲领卷（charter）。它回答两个问题——为什么构建
> axiom、axiom 的形态为何如此——并把答案锚定在正式卷（foundations / core /
> semantics / unified）的定义、公理与定理上。本卷不新增公理、构造子或规范性
> 义务；凡与正式卷冲突之处，以正式卷为准。愿景中属于假设或尚未验证的宣称，
> 逐条就地标注。

## 0. 定位

axiom 是异构复杂系统的交叉宪法层。定位由三个词构成，逐词展开。

- **宪法层**：只规定组合的合法性——什么能与什么连接、哪些义务必须被声明、
  哪些判定在编译期完成——不规定应用逻辑。类比既有事实：Rust 提供内存安全而
  不提供应用程序；axiom 提供拓扑安全、义务显式与物理可替换，而不提供系统。
- **交叉**：不同门类的复杂系统，各自最难的部分收敛为同一个问题集合（§1）。
  axiom 只构建这个交叉部分，不为任何单一门类定制。
- **异构复杂系统**：四个目标系统（§1）覆盖交互密集、状态密集、吞吐密集与
  任务密集四种负载形态；纲领的检验标准是四者能否无损分解到同一套概念上
  （§2）。

非目标随之确定：不是 all-in-one 框架；不做控制反转；不提供运行时容器；
不拥有用户的生命周期。宪法层给合法性，不给系统本身。

## 1. 四个目标系统与交叉问题集合

四个目标系统：MMO 游戏服务器、大型 GUI 桌面应用、高性能数据库、AI Agent。

这四类系统在当代架构实践中，各自最难的约两成工作收敛为同一个问题集合：

| 问题 | 形态 |
|---|---|
| 取消 | 请求沿组合树逆向传播，途经的每一层都必须如实响应 |
| 背压 | 上游速率约束沿组合树正向传播，不得被中间层静默吞掉 |
| 期限 | 时间约束作为值进入组合，而非散落在回调代码里 |
| 崩溃恢复 | 状态与副作用可从持久事件流重建 |
| 确定性重放 | 同一输入序列在同一二进制上得到同一轨迹 |
| 所有权分区 | 状态的独占边界在编译期划定，避免锁与竞态成为默认 |
| 上下文传播 | 身份、追踪与配置跨异步边界不丢失 |

单看任何一类系统，这些问题都有各自的工程答案；四类并置时，答案的形状相同：
拓扑（什么连接什么）、义务（谁必须做什么）、物理（等待与 I/O 如何实现）三者
必须分离，又必须在同一处声明。这是 axiom 的五概念封闭、义务账本与载体缝
所覆盖的部分（见 foundations 与 semantics 卷）。

支持收敛判断的四个社区事实级观察（外部项目对比与出处存于内部研究目录）：

1. 结构化并发已成为公知范式，其生产事故集中在"逃逸结构化作用域"：取消未
   传播、上下文跨异步边界丢失。结论：结构约束应进入定义层而非运行时惯例。
   axiom 的对应物是蓝图即任务树；取消沿蓝图边逆向的去激活是拓扑操作。
   （后一句是假设，待对拍评估，见 §6。）
2. 确定性仿真测试已成为数据库、金融与分布式基础设施领域的成熟实践。其三个
   前提——同步单线程确定性核、全部 I/O 经抽象层、显式故障注入点——与 axiom
   的架构（同步纯 step、全物理经载体缝、义务账本）逐条对应；axiom 系统按
   构造即具备确定性仿真的接入条件。
3. 持久化执行（事件日志、崩溃重放、副作用幂等）已成为 AI Agent 工程的常见
   形态。axiom 映射：agent 是 PortCell；模型与工具调用是带期限与取消的等待点；
   事件载体承担日志；重放即蓝图仿真。
4. 语言级同步/异步统一（异步析构、效应泛型）仍处多年期探索；就绪型与完成型
   两种 I/O 范式分裂固化在内核接口层。结论：同步/异步统一必须在缝层面自建，
   这是先手而非逆行；两种 I/O 范式是同一缝的两个载体成员，平台差异由实例层
   吸收（见 semantics 卷的三等待点契约与同步域轮询面）。

## 2. 四系统分解表：无损分解的检验

纲领的完整性检验是下表：四个目标系统各自的核心结构，能否在不丢失语义的
前提下分解为 axiom 的同一组概念（State / step / 等待点 / 载体 / 分区）。

| 系统 | State 与 step | 等待点 | 载体物理 | 分区 |
|---|---|---|---|---|
| MMO 服务器 | 实体状态与固定步长 tick | 客户端消息、持久化写回 | socket 缓冲、内核 I/O 接口 | 空间分片、兴趣管理 |
| GUI 桌面 | 组件树状态与事件步进 | 输入队列、合成器帧回执 | 帧缓冲、输入事件通道 | 窗口/组件边界 |
| 高性能数据库 | 索引与缓冲池、查询执行步 | 磁盘与网络 I/O | 日志结构存储、页缓存 | 表/分片/副本 |
| AI Agent | 会话状态与推理步 | 模型调用、工具调用 | 事件日志、消息队列 | 任务/子任务边界 |

四行各自使用不同的物理词汇，但结构槽位一一对应：State 独占、step 纯函数、
等待只在边界、物理经缝可换、分区即所有权。分解不失真的四行并存，是纲领
成立的最低证据；任何一行的失真都进入修正程序（见 §6 的证据纪律）。

## 3. 生态位：四性质同缝

axiom 占据的生态位由四个性质的合取定义，缺一即让位给既有形态：

| 性质 | 内容 | 单独存在的常见形态 |
|---|---|---|
| 拓扑类型化 | 组合结构是类型，非法接线不通过编译 | 组合器生态有组合、无类型化拓扑 |
| 义务显式 | 期限、取消、背压是声明项，不是注释 | 持久化执行有重放、无类型化拓扑 |
| 物理可换 | 等待与 I/O 经契约缝替换 | 确定性仿真系统封闭于自有运行时 |
| 确定性就绪 | 同步纯核 + 物理经缝，按构造可仿真 | 结构化并发运行时无编译期拓扑证明 |

四个性质单独出现时，各自都有大量成熟形态；同一缝上四者并存，是 axiom 主张
的空位。空位是否真实、是否被需要，由 §6 的证据纪律回答。

## 4. AI 时代论题：一致性机器

经济学前提：代码生成成本趋近于零时，稀缺资源从"写出代码"转移到"保持结构
一致性"。axiom 在此前提下的产品不是功能，是不变量；其形态是一致性机器。

- **机制一：结构从惯例变为类型。** 模型以人工不可评审的速率生成代码；人工
  评审的工作量不随生成量扩展，编译器检查随生成量零边际成本扩展。架构违规
  在 axiom 的组合语法里不存在对应写法——非法接线不通过编译，正如越界引用
  不存在于安全 Rust：不是防住了绕过，是那种写法不在语言里。
- **机制二：蓝图是结构推理面。** 措辞纪律：约束即写法，写法即思考。编译
  错误是最后防线而非第一机制；如同以 Rust 写作必然隐含所有权与生命周期的
  思考，以 axiom 构建的过程本身包含"哪些模块、如何组合、汇成什么系统"的
  分解——组合树就是系统，蓝图不是先于代码的文书。三个推论：
  - 试错发生在代数层：组合错误在编译期浮现，架构实验以秒计。当重组便宜、
    堆积昂贵时，搜索过程自然收敛到组合式架构。
  - 思考显化在工件里：隐藏语义被词汇吸收（State 独占、panic 边界已声明、
    时间作值、等待只在边界）之后，剩下的就是每一行本身的含义。工件把思考
    结构化编码进类型与拓扑；上下文丢失是 AI 时代的熵增，显化的思考是负熵
    机制。后来者（人或模型）继承的是可读的思考，而非需要逆向的代码。
  - 层界纪律引导复杂性流向：结构推理的对象是定义层蓝图，物理调整的对象是
    实例层；结构性腐烂对应复杂性长错层，而错层组合在 axiom 中是编译错误。
    长期维护不会顾此失彼。
- **机制三：确定性仿真循环。** 机制一与机制二使 agent 工程可表达为生成、
  仿真、验证、迭代的自动循环：同步纯 step 与全物理经载体缝使仿真即部署
  语义，无需人工逐行评审介入。

健康律（纲领对"建成"的定义）：复杂系统第一天第一行代码生长在正确抽象上，
且持续不腐烂。健康由两项构成——运行时零成本守恒（foundations 公理）与
书写本身的可读、可维护（机制二）。

## 5. 代换的六个尺度

unified 卷论证：静态/动态、插件、装载、驱动热插拔是同一个代换运算的两种
绑定模态。纲领把该运算的适用范围列全——六个尺度共用一个运算：

| 尺度 | 运算形态 | 判定时机 |
|---|---|---|
| 类型级 | 单态化（∀ 消解） | 编译期 |
| 模块级 | 布线（编译期绑定居留项） | 编译期 |
| 系统级 | Slot 与插件（∃ 引入） | 运行期 |
| 时间级 | 等待点（async = 完成的运行期绑定） | 运行期 |
| 拓扑级 | 分片（frame 律下的空间代换） | 运行期 |
| 组织级 | 实例整体替换（第二实现者纪律） | 构建期或运行期 |

## 6. 证据纪律与诚实边界

纲领的每条机制宣称绑定可证伪预测与分阶段证据；当前状态如实陈述：

- 已落地：core 编译期闭包、零成本探针（benches）、义务账本、T1–T9 定理的
  代码投影（见 core 卷 §5）。
- 在途：第二实现者对拍（T6 的第二次兑现）；取消作为拓扑操作的假设评估。
- 场所未到：可证伪预测清单（绑定下一个被实际研究的四类系统之一）。

诚实的天平——三组反权重，与机制宣称并列陈述：

1. 采用是协调问题。宪法层需要批准者；首批批准共同体是四类目标系统的实际
   构建者。证据链按阶段积累，不由单点演示替代。
2. 基座层时间尺度以十年计。可比先例（语言级异步生态从立项到生态收敛）走了
   近十年；排期按十年尺度，不按季度。
3. 与既有运行时惯例竞争。定位不是又一个平行惯例，而是 AI 工程工具链的编译
   目标：拓扑、义务与缝契约是机器可消费的形式化产物，供生成器与验证器
   直接读取。

开放项（已登记，非遗漏）：取消拓扑假设的对拍评估；State 可检查性、最坏
执行时间上界、中断驱动激活、重复与乱序投递维度——均为登记在案的宪法修正
候选，经修正程序处理（见 frontier-notes 与内部账本）。
